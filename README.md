# 🏒 Puck Master — Настольный хоккей
![Air Hockey Game](1774200950288.png)

## 💪 Начать играть - https://exorexic.github.io/aihokonl/

Классическая игра в аэрохоккей с милыми аватарками. Играйте вдвоём на одном телефоне или против умного бота.

## 🎮 Режимы
- 👥 **2 игрока** — левая половина экрана против правой
- 🤖 **Игра с ботом** — тренируйся против компьютера

## ✨ Особенности
- Управление пальцем
- Реалистичная физика шайбы
- Яркие аватарки (🐱🐶🐼🦊)
- Автоматический подсчёт голов

## 🎯 Как играть
Просто водите пальцем по экрану, отбивайте шайбу и забивайте голы!

**Приятной игры!** 🏒
